# Changelog

All notable changes to CodexQuotaBar are documented here.

## 0.1.0 - 2026-07-15

- Added compact menu bar quota status with remaining quota and reset time.
- Added compatible layouts for weekly-only and 5-hour plus weekly limits.
- Added configurable automatic refresh intervals.
- Added native Liquid Glass on macOS 26 and a visual-effect fallback on macOS 14-25.
- Restricted quota access to the official local Codex app-server and `account/rateLimits/read`.
- Added local cache hardening, sanitized diagnostics, and release signing support.
