# CodexQuotaBar v0.1.0

Initial open-source release of CodexQuotaBar.

## Highlights

- Compact macOS menu bar quota display.
- Compatible with weekly-only and 5-hour plus weekly quota accounts.
- Native Liquid Glass on macOS 26+, with a macOS 14-25 visual-effect fallback.
- Configurable automatic refresh intervals.
- Privacy-focused local app-server integration using only `account/rateLimits/read`.
- Hardened local cache permissions and sanitized diagnostics.

## Installation

This is a source-only release. A signed and notarized binary will be published
after a Developer ID certificate is configured. Until then, follow the
[build-from-source instructions](https://github.com/Shadowyuan616/CodexQuotaBar#installation).

Do not download or redistribute unofficial binary builds claiming to be this
release.
